# Replication package: "Reasoning in Turn: Pareto Optimality and Equal Treatment in Every Finite Game"

This package holds the scripts behind every computed number and every computational check cited in the paper and its Online Appendix, with their complete recorded outputs (`<script>.out` beside each script). The claims are listed at the end, numbered; the table of scripts gives, for each script, what it computes and the numbers of the claims it supports. Scripts whose name starts with `indep_` are independent recomputations, implemented separately from the paper's own programs; the paper relies on them only for the claims that no other script prints. Claims 19, 23, 24, 25, 40, 42, 46, 54, 59, 60 and 77 rest on them alone; claims 43, 55 and 56 rest on them in part, together with a script of the paper.

Requirements: Python 3.12 or later, the version tested (every output reproduces under Python 3.12.3 for `python3`; Python 3.12.3 with numpy 2.5.4 and scipy 1.18.1 under `uv run --with`; Linux x86_64). 7 scripts need packages (column "Needs"): `coop_theorems.py`, `demands_paper_examples.py`, `mixed_exante_single_line.py`, `mixed_single_logic.py`, `pte_extensions.py`, `indep_coop_side_claims.py`, `indep_vbe_and_mixed.py`. `pip install -r requirements.txt` installs them: numpy 2 or later, whose scalars print as `np.float64(...)` as in the recorded outputs, scipy and sympy. The other scripts use the standard library alone.

To run: from this folder, run the command of each script, as listed. Seeds are fixed in the scripts. Each command prints its recorded output, up to elapsed times and the messages of the package installer; scripts that write their own output file also rewrite `<script>.out`.

Contents: 41 scripts and 39 output files. Runtimes are wall times on one core of a desktop computer with no other job running; under parallel load they can be several times longer. Running every command once takes about 70 min.
